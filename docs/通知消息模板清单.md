# Leapex 利柏思通知消息模板清单

> 版本：V2.0
>
> 更新日期：2026-07-30
>
> 适用范围：管理后台【消息】、小程序【消息】
>
> 当前启用：10 个模板，其中 9 个面向客户或渠道商，1 个仅面向内部运营。

## 1. 整理原则

1. 同一任务最多发送两次：首次需要用户处理时通知一次；后台给出最终结果时再通知一次。
2. 同一审核任务的“通过”和“不通过”互斥，只能发送其中一个最终结果。
3. 不因时效、未读或未操作重复催办。
4. 不发送需要补充资料的中间过程通知。
5. 不发送订单状态通知、支付通知和到期提醒。
6. 服务只发送“开始办理”和“服务完成”，不发送办理中的节点变化。
7. 卡券只在首次成功发放时通知，不发送使用、核销或到期消息。
8. 渠道商只保留审核通过、推荐客户下单、佣金到账。
9. 用户提交订单后，只给内部运营发送一次系统通知，不下发至客户小程序。

## 2. 模板字段

管理后台每个消息模板必须维护以下数据：

| 字段 | 说明 |
|---|---|
| 消息分类 | 合规通知、服务通知、卡券通知、渠道商通知或系统通知 |
| 触发条件 | 唯一业务事件及发送次数限制 |
| 标题模板 | 消息标题，支持变量占位符 |
| 内容模板 | 消息正文，支持变量占位符 |
| 小程序页面路由 | 用户点击消息后进入的小程序路径 |
| 路由页面描述 | 运营人员可读的目标页面名称 |
| 接收对象 | 客户、渠道商或内部运营人员 |

内部运营模板不配置客户小程序路由，点击后应进入管理后台对应业务页。

## 3. 启用模板总表

### 3.1 合规通知

#### CP-001｜请完成 KYC 认证

- 消息分类：合规通知
- 触发条件：业务首次进入 KYC 待认证状态时发送一次。
- 标题模板：`请完成 KYC 认证`
- 内容模板：`{客户姓名}，办理「{服务名称}」需要完成 KYC 认证。请进入认证页面提交资料。`
- 小程序页面路由：`/pages/kyc/index?taskId={任务编号}`
- 路由页面描述：KYC 认证页
- 接收对象：客户

#### CP-002｜KYC 认证已通过

- 消息分类：合规通知
- 触发条件：KYC 审核通过时发送一次；与 CP-003 互斥。
- 标题模板：`KYC 认证已通过`
- 内容模板：`{客户姓名}，您的 KYC 认证已通过，「{服务名称}」将继续办理。`
- 小程序页面路由：`/pages/kyc/result?taskId={任务编号}&result=approved`
- 路由页面描述：KYC 已认证详情
- 接收对象：客户

#### CP-003｜KYC 认证未通过

- 消息分类：合规通知
- 触发条件：KYC 审核不通过时发送一次；与 CP-002 互斥。
- 标题模板：`KYC 认证未通过`
- 内容模板：`{客户姓名}，您的 KYC 认证未通过，原因：{驳回原因}。请进入认证页重新提交。`
- 小程序页面路由：`/pages/kyc/edit?taskId={任务编号}`
- 路由页面描述：KYC 资料修改页
- 接收对象：客户

### 3.2 服务通知

#### SV-001｜服务开始办理

- 消息分类：服务通知
- 触发条件：服务首次进入“办理中”状态时发送一次。
- 标题模板：`{服务名称}已开始办理`
- 内容模板：`{客户姓名}，{公司名称}的「{服务名称}」已开始办理，可进入服务详情查看。`
- 小程序页面路由：`/pages/order/detail?bizId={业务编号}`
- 路由页面描述：服务进度详情
- 接收对象：客户

#### SV-002｜服务完成

- 消息分类：服务通知
- 触发条件：服务首次进入“已完成”状态时发送一次。
- 标题模板：`{服务名称}已完成`
- 内容模板：`{客户姓名}，{公司名称}的「{服务名称}」已完成，交付结果已更新，请进入服务详情查看。`
- 小程序页面路由：`/pages/order/detail?bizId={业务编号}`
- 路由页面描述：服务完成与交付详情
- 接收对象：客户

### 3.3 卡券通知

#### MK-001｜卡券首次发放

- 消息分类：卡券通知
- 触发条件：卡券首次成功发放到用户账户时发送一次。
- 标题模板：`您已获得{券名称}`
- 内容模板：`{客户姓名}，{券名称}已发放至您的账户，请进入卡券中心查看使用规则。`
- 小程序页面路由：`/pages/coupon/index`
- 路由页面描述：卡券中心
- 接收对象：客户

### 3.4 渠道商通知

#### CH-001｜渠道商审核通过

- 消息分类：渠道商通知
- 触发条件：渠道商审核通过且推荐码生效时发送一次。
- 标题模板：`渠道合作审核已通过`
- 内容模板：`{渠道商姓名}，您的渠道合作审核已通过，推荐码 {推荐码} 已生效，请进入渠道工作台查看。`
- 小程序页面路由：`/pages/channel/index?tab=overview`
- 路由页面描述：渠道工作台－概览
- 接收对象：渠道商

#### CH-002｜推荐客户下单

- 消息分类：渠道商通知
- 触发条件：推荐客户首次成功提交订单时发送一次。
- 标题模板：`推荐客户已下单`
- 内容模板：`客户 {客户姓名脱敏} 已通过推荐码 {推荐码} 下单「{服务名称}」，可进入渠道工作台查看归属记录。`
- 小程序页面路由：`/pages/channel/index?tab=customers`
- 路由页面描述：渠道工作台－归属客户
- 接收对象：渠道商

#### CH-003｜佣金到账

- 消息分类：渠道商通知
- 触发条件：佣金打款状态首次变为“已到账”时发送一次。
- 标题模板：`佣金已到账`
- 内容模板：`{结算月份}佣金 {币种}{佣金金额} 已到账，请进入渠道工作台核对收款记录。`
- 小程序页面路由：`/pages/channel/index?tab=commission`
- 路由页面描述：渠道工作台－我的佣金
- 接收对象：渠道商

### 3.5 系统通知

#### SY-001｜客户提交新订单

- 消息分类：系统通知
- 触发条件：用户首次成功提交订单后，通知运营人员一次。
- 标题模板：`【运营】客户已提交新订单`
- 内容模板：`客户 {客户姓名} 已提交「{服务名称}」，业务编号 {业务编号}，请进入管理后台处理。`
- 小程序页面路由：不适用
- 路由页面描述：管理后台－订单详情（内部运营，不下发客户小程序）
- 接收对象：内部运营人员

## 4. 展示与权限

### 管理后台【消息】

- 展示全部 10 个模板。
- 支持按消息分类筛选。
- 列表展示模板编号、消息分类、触发条件、标题模板、内容模板、小程序页面路由、路由页面描述和接收对象。
- 编辑弹窗可维护消息分类、触发条件、标题模板、内容模板、小程序页面路由和路由页面描述。
- 内部运营模板必须标记为内部消息，禁止进入客户消息队列。

### 小程序【消息】

- 客户只看到发送给自己的合规、服务和卡券消息。
- 渠道商只看到发送给自己的渠道商消息，以及其作为普通客户时产生的客户消息。
- 内部运营系统通知不得在客户或渠道商小程序中展示。
- 消息卡片展示消息分类、标题、内容和目标页面描述。
- 点击消息后按小程序页面路由进入对应页面。
- 审核“通过”和“不通过”结果只显示实际发生的一条，不得同时出现。

## 5. 去重与互斥

### 去重键

建议使用：

```text
dedupe_key = template_code + ":" + business_object_id
```

同一个 `dedupe_key` 只允许成功发送一次。发送失败重试沿用原发送记录，不新建第二条用户消息。

### 单任务两次上限

| 任务类型 | 第一次 | 第二次 |
|---|---|---|
| KYC | CP-001 待认证 | CP-002 通过或 CP-003 不通过 |
| 服务 | SV-001 开始办理 | SV-002 服务完成 |

CP-002 与 CP-003 使用同一结果互斥组：

```text
mutex_group = "kyc_result:" + task_id
```

互斥组内任一模板成功发送后，其他结果模板不可再发送。

## 6. 已移除的消息

以下内容不得继续出现在管理后台模板、小程序消息中心或自动发送任务中：

- 订单创建、订单状态变化、订单取消等订单通知
- 账单生成、待支付、支付成功、回单确认等支付通知
- 需要补充资料、资料已补充、资料审核中等中间通知
- 服务节点更新、已递交、制作中、已寄出等中间过程通知
- 年审、证件、服务、卡券等到期提醒
- 因未读、未处理或剩余时间产生的重复催办
- 卡券使用、核销、失效或过期通知
- 渠道商申请提交、审核驳回、待签约、签约邀请、签约过期等通知

登录验证码属于身份验证安全消息，不进入小程序【消息】模块，也不计入本清单。

## 7. 验收标准

1. 管理后台消息模块只显示本清单 10 个启用模板。
2. 每个客户或渠道商模板均配置有效的小程序页面路由和页面描述。
3. 点击小程序消息能进入对应的 KYC、服务详情、卡券或渠道工作台页面。
4. 内部运营消息不会出现在客户或渠道商小程序。
5. KYC 单任务最多发送两条，且通过与不通过不同时发送。
6. 单项服务最多发送开始办理和服务完成两条。
7. 订单、支付、补资料、中间进度、到期及重复催办消息均不可触发。
