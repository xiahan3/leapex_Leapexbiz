特别说明：

### 0.2 本次修订结论

- 服务目录共 17 个香港商品：12 个在线标准商品、5 个面议商品。
- 所有在线标准商品在下单时统一先进入“选择办理公司”。

- 订单办理节点按各商品的最新流程生成；账单中的“下单/支付”不重复计入业务办理进度。
- 起始页当前只展示香港；新加坡、迪拜、BVI 不作为本期可办理地区。
- 起始页与应用内页采用两套协调视觉：起始页为香港实景照片、深蓝蒙层和绿色品牌图标；应用内页为浅色底、暖橙强调色和绿色/蓝色状态色。

## 1. 产品定义

### 1.1 产品定位

Leapex 利柏思小程序是面向香港公司服务客户的移动办理入口，覆盖：

- 渠道口令码准入；
- 服务浏览、下单和支付；
- 公司档案选择与维护；
- 公司名称查册、公司注册、年审、税务、工商变更、商标和地址服务；
- KYC 客户尽调；
- 订单进度、顾问备注和交付物查看；
- 面议服务预约。

### 1.2 产品目标

1. 让用户在下单前看懂价格、时效、交付内容、材料与办理流程。
2. 让标准商品形成“选公司 → 确认订单 → 支付 → 提交资料 → 办理”的完整闭环。
3. 让每个商品使用自己的字段、KYC 规则和办理节点。
4. 让订单状态和办理进度可追踪，减少重复询问。
5. 让公司档案沉淀为年审、变更与复购的统一入口。
6. 让面议商品形成可跟进的咨询线索，同时避免在价格未确认前在线收款。

### 1.3 本期不包含

- 真实微信登录、手机号登录和验证码；
- 真实口令码校验；
- 真实微信支付、支付宝和银行到账核销；
- 真实 OCR、证件识别、活体或人脸核验；
- 真实 KYC、PEP、制裁名单筛查；
- 真实文件上传、下载和电子签署；
- 真实邮件、短信和客服系统；
- 真实公司注册处、税务局或知识产权署接口；
- 新加坡、迪拜、BVI 商品与履约。

## 2. 用户与核心场景

| 用户角色 | 核心诉求 | 主要入口 |
|---|---|---|
| 新客户 | 了解香港服务、核名、注册、查看明确价格 | 口令码起始页、新客首页、服务目录 |
| 已有香港公司的客户 | 年审、税务、变更、商标、地址服务与进度管理 | 老客首页、我的公司、订单 |
| 渠道客户 | 使用口令码进入并绑定来源 | 起始页口令码 |
| 顾问/运营 | 承接面议咨询、维护订单节点、补充材料和备注 | 后台，本 PRD 只定义用户端结果 |
| 合规人员 | 审核 KYC 资料与反馈不通过原因 | 后台，本 PRD 只定义用户端状态 |

核心场景：

1. 新客户使用口令码进入，先查册，再办理公司注册。
2. 已有公司客户从年审提醒进入，选择公司并续办年审。
3. 用户购买工商变更、税务、商标或独立注册地址服务。
4. 用户预约审计、股份转让、公司注销、工位或办公室等面议服务。
5. 用户在订单中查看当前办理节点、顾问备注、补充材料与交付物。

## 4. 全局业务规则

### 4.1 在线标准商品主流程

```mermaid
flowchart TD
    A["服务详情"] --> B["选择办理公司"]
    B --> C{"已有公司？"}
    C -->|是| D["选择公司"]
    C -->|否| E["新增已有公司"]
    E --> F["公司基本信息"]
    F -->|保存| G["自动返回订单流程"]
    D --> H["订单确认"]
    G --> H
    H --> I["生成订单与账单"]
    I --> J{"支付方式"}
    J -->|人民币| K["微信/支付宝"]
    J -->|港币| L["银行转账并上传回单"]
    K --> M["确认到账并启动办理"]
    L --> N["待运营确认到账"]
    N --> M
    M --> O["提交商品所需信息"]
    O --> P{"该商品需要 KYC？"}
    P -->|是| Q["KYC 认证与人工审核"]
    P -->|否| R["进入后续业务办理"]
    Q --> R
    R --> S["订单进度/交付"]
```

规则：

- 公司选择是在线标准商品的统一前置步骤。
- “公司基本信息”页与“我的－我的公司－新增公司”使用同一页面和字段。
- 保存公司后，不返回服务详情，直接进入订单确认。
- 订单确认必须显示当前商品名称、原价、优惠、应付合计和服务条款。
- 人民币与港币金额从当前商品配置读取。
- 港币上传回单后状态为“待确认”，运营确认到账前不得显示“已到账”或启动业务。
- 商品信息提交后，按商品配置判断是否进入 KYC。

### 4.2 面议商品主流程

```mermaid
flowchart TD
    A["服务详情：价格面议"] --> B["预约咨询"]
    B --> C["二次确认弹窗"]
    C -->|确认| D["预约成功"]
    D --> E["顾问 24 小时内联系"]
    E --> F["线下确认需求与报价"]
    F --> G["线下签约"]
    G --> H["后台新增正式订单"]
```

规则：

- 用户端不在线支付、不在线签署、不展示未经确认的金额。
- 预约成功后生成咨询记录，可在订单列表查看“待顾问联系”。
- 正式订单由顾问/运营在后台创建。

### 4.3 商品级 KYC 规则

| 类型 | 商品 |
|---|---|
| 在线流程需要 KYC | 新设香港本地有限公司、年审服务、董事变更、变更秘书公司、商标注册申请、商标注册续期、独立注册地址 |
| 在线流程不进入 KYC | 公司名称查册 + 商标查询、公司薪俸税、个别人士报税、变更注册地址、公司更名 |
| 面议线下确认 | 审计（含理账）、股份转让、公司注销、工位租赁、独立办公室租赁 |

面议商品如在线下成交后需要 KYC，由后台订单与正式合同规则决定，不在预约阶段强制用户进入 KYC。

### 4.4 订单进度规则

- 每个商品使用自己的 `process` 生成订单节点。
- 支付完成后，“下单/支付”节点标记为完成，第一个业务节点进入进行中。
- 用户提交资料时，只推进“提交/信息核对/确认接任”类节点。
- 用户提交 KYC 时，只推进 KYC 节点。
- 商品配置要求 KYC、但原办理流程未单列 KYC 时，系统在资料提交后自动插入“KYC 认证”节点。
- 订单详情只统计业务节点；以“下单”或“支付”开头的账单节点不计入办理进度百分比。
- 全部业务节点完成后，订单状态为“已完成”，账单/交付状态为“已交付”。

## 6. 商品表单

### 6.1 公司名称查册 + 商标查询

- 顶部项目多选：公司名称查册、商标查询；至少选择一项。
- 查册方式：以全名查册、以名称起首查册。
- 公司名称：繁体中文和英文至少填写一项。
- 输入简体中文时，页面提示转换后的繁体文本。
- 商标查询：商标名称/关键字；如需图形查询，可补图样。
- 联系邮箱。
- 提交后进入“顾问人工核名中”，约 1–2 个工作日出结果。

### 6.2 新设香港本地有限公司

注册资料使用四页 NNC1 向导。

**第 1 页：公司资料**

- 拟用公司全名（繁体中文）；
- 拟用公司全名（英文）；
- 拟经营业务性质（HSIC）；
- 注册办事处地址：秘书公司地址/需要租赁办公室；
- 公司电邮；
- 股份类别、币种、发行股数、认购股本。

**第 2 页：成员/董事**

- 身份：创办成员、董事，可多选；
- 证件类型：香港身份证、护照、其他；
- 证件照片；
- OCR 识别并回填姓名、证件号；
- 手持证件照片；
- 通讯地址；
- 常驻地址，默认同通讯地址；
- 非香港地址展示国家/地区，默认中国；
- 联络邮箱。

**第 3 页：组织章程**

- 样本 A（简化格式，推荐）；
- 样本 B；
- 章程语言：英文、繁体中文；
- 章程 PDF 预览。

**第 4 页：人工预审**

- 汇总公司、成员、股本、地址和章程信息；
- NNC1 预览；
- 确认资料真实完整；
- 暂存或提交人工预审。

支付完成页同时展示两个待办入口：

1. 完成 KYC 实名认证；
2. 提交公司注册信息。

两项均完成后才进入人工预审与后续文件编制。

| 商标注册申请 | 商标名称、商标图样（如需）、申请类别 Class、申请人、联系邮箱 |
| 商标注册续期 | 商标名称、商标注册编号、续期年度 |
| 独立注册地址 | 公司名称/拟注册名称、用途、联系人及手机、备注 |

## 7. 页面需求

### 7.1 起始页

| 项目 | 需求 |
|---|---|
| 服务地区 | 只展示香港 |
| 品牌 | 绿色 Leapex 图标 |
| Slogan | “开启您的海外商业布局”，分两行 |
| 口令码标题 | “口令码” |
| 按钮 | “输入口令码开始服务” |
| 校验 | 必须输入 6 位口令码；无效时展示明确错误 |
| 跳过 | 本期不提供 |

### 7.2 服务目录

- 类型筛选：全部、核名商标、注册、年审服务、变更、记账报税、商标、地址租赁。
- 目录展示 17 个香港商品。
- 商品卡展示名称、简述、时效、HKD 价格或“面议”。
- 非香港地区若保留筛选占位，不得产生可下单商品。
- 空态：“该地区暂无此类服务，请切换筛选条件。”

### 7.3 服务详情

统一展示：

1. 商品名称；
2. 价格/面议；
3. 简要介绍；
4. 服务交付内容；
5. 办理时效；
6. 所需材料；
7. 办理流程；
8. 详细说明；
9. 底部主操作。

操作规则：

- 在线商品：按钮“立即办理”。
- 面议商品：按钮“预约咨询”。
- 公司名称查册 + 商标查询：展示 HKD 99 / ¥89 与免费券抵扣结果。

### 7.4 选择办理公司

- 页面显示当前商品名称。
- 展示已有公司列表。
- 选择公司后进入订单确认。
- “新增已有公司”进入“公司基本信息”。
- 公司基本信息字段：中文名称、英文名称、CI、BR、成立日期。
- 中文名与英文名至少填写一个；CI、BR 在原型阶段允许暂不填写。
- 从结算流程新增并保存后，自动选择该公司并进入订单确认。

### 7.5 订单确认

- 当前商品、商品说明、商品价格；
- 原价、优惠金额、应付合计；
- 当前选中的办理公司；
- 服务条款勾选；
- 未勾选条款时禁止提交；
- 提交后生成唯一订单号和账单号。

### 7.6 账单支付

- 三步提示：下单、支付、办理。
- 币种：人民币、港币。
- 金额必须读取当前商品：
  - 有明确 CNY 价格时使用商品配置；
  - 无独立 CNY 配置时，可按 HKD × 0.9 取整作为原型展示。
- 优惠券只展示当前商品可用券；无券时提示“本单暂无可用优惠券”。
- 人民币：微信支付、支付宝。
- 港币：展示香港收款账户，转账后上传回单。
- 回单页的金额和账单参考号从当前订单带入，不使用固定示例金额。
- 回单提交后：
  - 账单状态：待确认；
  - 订单阶段：待确认到账；
  - 提示运营核对到账后启动服务。

### 7.7 支付结果与信息提交

在线支付成功：

- 标题：“支付成功”；
- 文案：“已收到你的款项。请继续提交本次办理所需的信息。”；
- 下一步按钮：提交办理信息。

资料提交后：

- 需要 KYC：提示“办理所需信息已提交。最后一步：完成 KYC 实名认证（香港持牌 TCSP 合规必做）。”
- 不需要 KYC：提示顾问将继续编制、签署或递交，用户可在订单中查看进度。

港币回单：

- 标题：“回单已提交”；
- 文案：“运营人员将在网银核对到账。确认到账后，订单会自动进入办理流程。”

### 7.8 KYC

五段展示：

1. 合规说明与同意；
2. 身份认证：证件类型、证件照片、手持证件照、邮箱验证码；
3. 地址证明：近 3 个月内；
4. 业务声明：业务性质、交易类型、资金来源、补充说明；
5. 提交审核。

状态：

- 未提交；
- 人工审核中；
- 已通过；
- 未通过，展示逐项原因并允许定向重传。

原型审核时效文案统一为“约 1 个工作日”，避免同一页面同时出现 24 小时和 48 小时。

### 7.9 订单列表与详情

订单状态：

- 待支付；
- 待顾问联系；
- 服务中；
- 已完成；
- 已取消。

账单状态：

- 待支付；
- 待确认；
- 已到账；
- 面议；
- 办理中；
- 已交付；
- 已作废。

订单列表：

- 按公司分组；
- 显示服务、订单号、当前阶段、金额和状态；
- 面议咨询金额显示“—”；
- 支持状态筛选。

订单详情：

- 公司名、商品名、订单号、口令码；
- 当前阶段与进度百分比；
- 账单信息；
- 业务节点；
- 每个节点可包含用户已提交资料、顾问补充文件和顾问备注；
- 下单和支付节点不纳入办理进度。

### 7.10 我的公司

- 展示公司中英文名、CI、BR、状态和年审信息。
- 支持新增公司。
- 无进行中订单的公司可以二次确认后删除。
- 有进行中订单的公司不可删除。
- 公司档案是订单、交付物和年审提醒的统一归属主体。

### 7.11 面议咨询

- 二次确认文案包含当前商品名；
- 明确顾问将在 24 小时内联系；
- 预约成功后咨询记录状态为“待顾问联系”；
- 预约阶段不显示在线支付、KYC 和正式合同；
- 正式成交后由后台新增订单。

## 9. 异常与边界

| 场景 | 处理 |
|---|---|
| 口令码少于 6 位 | 阻止提交，提示“请输入 6 位口令码” |
| 口令码无效 | 提示“请确认口令码” |
| 未选择办理公司 | 不允许进入订单确认 |
| 公司中英文名均为空 | 不允许保存 |
| 未勾选服务条款 | 不允许生成订单 |
| 当前商品无优惠券 | 优惠券入口提示“本单暂无可用优惠券” |
| 在线支付失败/取消 | 保持待支付，可重新支付 |
| 港币回单待核对 | 保持待确认，不提前启动业务 |
| KYC 未通过 | 展示未通过项目与原因，只重传相关资料 |
| 面议商品点击办理 | 只进入预约咨询，不进入账单 |
| 公司有进行中订单 | 禁止删除公司 |
| 订单取消 | 订单为已取消，账单为已作废 |
| 非香港地区 | 本期不展示可办理商品 |
