01总览数据释义

渠道商总览

  • • 当天 / 累计注册渠道商：按统计日或上线以来成功发放口令码的渠道主体去重，同一主体重复发码只计 1 个。
  • • 已注册未签约：已发放口令码、尚未完成电子签约的渠道商存量。
  • • 已签约：已完成电子签约的渠道商累计数。

客户注册总览

  • • 当天 / 累计注册客户：按统计日或上线以来首次完成小程序注册的终端企业用户去重。
  • • 今日活跃用户：统计日内发生任一有效操作的去重用户。
  • • 老用户活跃：当日活跃且注册时间早于统计日的去重用户。

客户下单总览

  • • 当天 / 累计付费用户：统计日内首次完成支付，或上线至统计日曾至少一次支付成功的去重用户。
  • • 订单数量：支付成功的订单数；未支付、已取消订单不计。
  • • 订单金额（¥）：人民币实收金额；退款金额按实际退款扣减。
  • • 当天 / 累计口径：分别统计当日 00:00–23:59，或产品上线日至所选统计日的数据。

02付费转化漏斗数据释义

  • • 活跃用户：统计日内发生任一有效操作的去重用户。
  • • 访问商品：进入任一服务详情页，同一用户重复访问不重复统计。
  • • 开始下单：用户进入确认订单页，同一用户重复进入不重复统计。
  • • 提交订单：订单创建成功的去重用户。
  • • 支付成功：收到支付成功回调的去重用户。
  • • 转化率：阶段转化率为当前阶段去重人数 ÷ 上一阶段去重人数；整体支付转化率为支付成功人数 ÷ 活跃用户数。

03渠道入驻漏斗数据释义

  • • H5 访问：进入营销 H5 的访客 UV，同一访客重复访问不重复统计。
  • • 获取验证码：用户输入手机号并成功获取短信验证码；同一手机号重复获取不重复统计。
  • • 提交申请：渠道合作申请表单提交成功，同一申请主体重复提交不重复统计。
  • • 审核通过：运营人员在管理后台审核通过的去重申请主体。
  • • 完成签约：电子合同完成签署的去重渠道主体。
  • • 转化率：阶段转化率为当前阶段去重人数 ÷ 上一阶段去重人数；整体签约转化率为完成签约数 ÷ H5 访问 UV。
